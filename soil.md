# Solar Powered Soil Moisture Sensor
## Purpose
While I've done a lot of work with Arduino for basic, high level microcontroller projects in the past, I wanted to learn more about home automation via the ESP32 chip and its built-in Wi-Fi functionality. A practical application is to monitor soil moisture for a specific plant and overall garden health if I choose to build multiple nodes in a modular setup. Since the original intended use of the sensor is for outdoor use, I opted for a solar power to charge the battery, which will power the ESP32 and sensor when active.
