# Solar Powered Soil Moisture Sensor
## Preface
While I've done a lot of previous work with Arduino for basic, high level microcontroller projects, I wanted to learn more about the ESP32 chip and its built-in Wi-Fi and BLE functionalities. In addition, I wanted to integrate over-the-air data collection to truly make this an IoT project. This system is essentially a soil moisture monitor for a specific plant or garden that logs and inferences water absorption over time. To fully self-contain this design, I opted for solar power to charge the battery, which powers the ESP32 and sensor when active.
